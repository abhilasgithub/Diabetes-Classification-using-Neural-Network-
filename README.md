# Diabetes Classification using Neural Network

A deep learning project designed to classify and predict diabetes risk using neural networks built with Python. This repository follows a modular code structure, separating data handling, model architecture, and source execution logic.

## Project Structure

```text
Diabetes-Classification-using-Neural-Network-/
├── data/               # Raw and processed dataset files
├── models/             # Saved model weights and architecture checkpoints
├── src/                # Source code for data preprocessing, training, and evaluation
├── requirements.txt    # Project dependencies
└── README.md           # Project documentation
